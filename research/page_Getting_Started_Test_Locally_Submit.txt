b'Getting Started: Test Locally & Submit This guide walks you through building an agent, testing it locally, and submitting it to this simulation competition.\n\n### Test Locally\n\nInstall the environment from PyPI (any recent release that includes Kaggriculture):\n\n```bash\npip install -U kaggle-environments\n```\n\nRun a game from Python or a notebook \xe2\x80\x94 you can pass agent functions directly, or paths to `.py` files:\n\n```python\nfrom kaggle_environments import make\n\nenv = make("kaggriculture", configuration={"episodeSteps": 720}, debug=True)\nenv.run([agent, "random"]) # or env.run(["main.py", "random"]) to load from a file\n\n# View result\nfinal = env.steps[-1]\nfor i, s in enumerate(final):\n print(f"Player {i}: reward={s.reward}, status={s.status}")\n\n# Render in a notebook\nenv.render(mode="ipython", width=1200, height=800)\n\n# Or dump a replay JSON for the visualizer / offline analysis\nimport json\nwith open("replay.json", "w") as f:\n json.dump(env.toJSON(), f)\n```\n\nThree built-in agents are available by name: `"pass"`, `"random"`, and `"starter"` (a deterministic baseline).\n\n### Set Up the Kaggle CLI\n\nInstall the CLI:\n\n```bash\npip install kaggle\n```\n\nYou\'ll need a Kaggle account \xe2\x80\x94 sign up at https://www.kaggle.com if you don\'t have one.
